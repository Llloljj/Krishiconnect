# 🏗️ KISAN MADAD: Architecture (v2.0)

## Stack
- **Frontend**: HTML5, Vanilla CSS, JS (ES6+)
- **Backend**: Node.js (Express)
- **AI Engine**: NVIDIA NIM (Inference Microservices)
- **Database**: Supabase (PostgreSQL)

## Core Modules
1. **B2B Matcher**: NIM-powered inference to match companies with farmers.
2. **Contract Hub**: Lifecycle management for agricultural contracts.
3. **Agri-AI Advisory**: Real-time crop and weather insights.
